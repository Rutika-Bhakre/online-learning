Online Learning Portal

A modern Online Learning Platform built with React.js that allows users to explore courses, view course details, and experience a clean learning interface. The project focuses on responsive UI, reusable components, and modern frontend development practices.

🚀 Live Demo

🔗 https://online-learning-ten-gules.vercel.app/

💻 GitHub Repository

✨ Features

Browse available courses
Course detail pages
Clean and modern UI
Fully responsive design
Fast performance using React
Reusable components architecture

Tech Stack :-

⚙️ Installation & Setup

Clone the repository

git clone https://github.com/Rutika-Bhakre/online-learning.git

Go to frontend folder
cd frontend
Install dependencies
npm install
Run the development server
npm start
